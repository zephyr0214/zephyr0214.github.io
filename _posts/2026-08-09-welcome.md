This is a sample post used to verify the Posts section. It will appear in the post list on `/posts/`, in the RSS feed (`feed.xml`), and in the sitemap.

## How to Add Notes

- Put Markdown files in the `_posts/` directory.
- Name each file as `YYYY-MM-DD-title.md`; the date is taken from the filename.
- Add a `title` in the YAML front matter.
- Start the body from a `##` heading so it does not duplicate the page title shown above.

Delete this sample whenever you are ready to publish your own notes.
